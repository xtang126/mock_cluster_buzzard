\begin{abstract}
This document is the technical reference for the
\modname{Xin\_MockDataVector.ipynb} forward model: a Buzzard-halo
DES~Y3-like cluster mock that layers the Costanzi+2026 (C26) optical
selection systematics on top of the raw simulation outputs to produce
the two pieces a likelihood needs --- a binned cluster number-count
vector $N(\lob, \zob)$ and a binned tangential-shear data vector
$\langle\gamma_t(R)\,|\,\lob, \zob\rangle$.  The pipeline draws an
intrinsic richness $\ltr$ from the C26 mass--richness relation
(Eq.~15), projects it to an observed richness $\lob$ via the
Costanzi+2019 (C19) Eq.~6 mixture (Gaussian core + EMG projection
tail), and constructs the lensing data vector along two parallel
routes: a catalog-driven empirical $\Bsel$ ratio that stacks
\texttt{LAMBDA\_CHISQ}/\texttt{Z\_LAMBDA} selected clusters and
divides by an $(M, z_{\rm true})$-matched random reference
(Wu+2022, Costanzi+2026), and an analytical C26 Eq.~C1 fitting
function applied to the C19 forward-model stack.  Boost-factor
contamination is left for a follow-up.  All code lives in this
directory; the production notebook is
\pyfile{Xin\_MockDataVector.ipynb} and the canonical output is
\pyfile{/global/u2/x/xintang/mocks/mock/Xin\_MockDataVector.npz}.
\end{abstract}

\section{Pipeline topology}
\label{sec:topology}

The notebook executes the following sequence of stages:

\begin{center}
\fbox{\parbox{0.95\linewidth}{\centering
\modname{halo\_load} $\to$ \modname{photoz\_proxy} $\to$
\modname{sample\_lambda\_true} $\to$ \modname{sample\_lambda\_obs}
$\to$ \modname{number\_counts} $\to$ \modname{stack\_sigma} $\to$
\modname{redmapper\_bin} $\to$ \modname{mass\_match\_random} $\to$
\modname{B\_sel\_emp} $\to$ \modname{C1\_analytical} $\to$
\modname{save\_npz}}}
\end{center}

The first three stages are the forward model: select host halos
above $\log_{10} M_{\rm vir} = 13$ in $z \in [0.20, 0.65]$ (with the
Buzzard $0.33 \le z \le 0.37$ box seam excised), add a DES~Y3-like
photo-$z$ scatter to produce $\zob$, and draw $\ltr$ and $\lob$ from
the C26/C19 kernels.  The next four stages build the lensing data
vector: stack \blk{Sigma}/\blk{DeltaSigma} in $(\lob, \zob)$ bins,
re-stack on the catalog redMaPPer outputs (\blk{LAMBDA\_CHISQ},
\blk{Z\_LAMBDA}), construct the $(M, z_{\rm true})$-matched random
reference, and form $\Bsel^{\rm emp}(R)$.  The last two stages emit
the analytical C1 corrections that an MCMC chain would consume in
place of the per-sample stack, and persist everything to a single
\texttt{.npz} archive.

\section{Shared conventions}
\label{sec:conventions}

\paragraph{Cosmology.}  \texttt{FlatLambdaCDM(H0=70, Om0=0.3,
Ob0=0.046, Tcmb0=2.725)} via \texttt{astropy.cosmology}, matching
the Buzzard simulation cosmology used by the upstream halo catalogue
(\texttt{cosmo0} in cell~3 of the notebook).

\paragraph{Units.}  Per-halo $\Sigma, \Delta\Sigma$ from
\pyfile{floc.profile\_output\_fname} are stored in physical
$M_\odot/\mathrm{pc}^2$ (FITS header \texttt{TUNIT9}, \texttt{TUNIT10}).
Radii \blk{rp\_phys\_mpc} (from \pyfile{radial\_bins\_phys\_mpc.py}) are
in physical Mpc, with $N_R = 15$ log-spaced bins between
$0.0323$ and $30\,\mathrm{Mpc}$.  Halo masses \blk{Mvir} are in
$\hMsun$ (FITS header \texttt{TUNIT2}); the C26 mass--richness
parameters are quoted in $M_\odot$, so \blk{Mvir} is multiplied by
$h$ on read where the comparison demands it (e.g.\ the \modname{hmf}
cross-check in \S\ref{sec:hmf-check}).

\paragraph{Halo selection.}  Mirrors \pyfile{0-MakeMock.ipynb}:
\texttt{pid == -1} (host halos only), $0 \le \cos i \le 1$
(measured), drop the simulation-box seam $0.33 \le z < 0.37$, then
require $0.20 \le \ztr \le 0.65$ and $\log_{10} M_{\rm vir} \ge 13$.
This yields $\sim 5.83 \times 10^5$ halos.

\paragraph{Binning.}  The default richness edges are
$\texttt{LBDBINS} = \{5, 15, 25, 40, 160\}$ (4~bins) and the
photo-$z$ edges are
$\texttt{ZMIN\_LIST} = \{0.20, 0.37, 0.51\}$,
$\texttt{ZMAX\_LIST} = \{0.32, 0.51, 0.64\}$ (3~bins).  These match
the legacy \pyfile{createDataVector.ipynb} edges so the data vector
saved here can be cross-compared.  An alternative DES~Y3-style
binning ($\{20, 30, 45, 60, 500\}$, $\{0.20, 0.35, 0.50, 0.65\}$)
is also supported in the analytical C1 panel of \S\ref{sec:c1}.

\paragraph{Photo-$z$ proxy.}  The DES~Y3 redshift uncertainty is
modelled by a per-halo Gaussian
\begin{equation}
  \zob = \ztr + \sigma_z(1 + \ztr)\,\mathcal N(0, 1),
  \qquad \sigma_z = 0.01,
\end{equation}
clipped at $\zob \ge 0.02$ to avoid unphysical negatives.  This is a
deliberate stand-in for the redshift- and colour-dependent kernel of
Myles+2021; it captures the dominant scatter but not the tails.
Throughout the notebook $\lob$ is drawn at $\zob$ (not $\ztr$), and
all observed-frame binning uses $\zob$ for self-consistency with the
projection kernel.

\paragraph{Random seeds.}  All Monte-Carlo draws use a single
\texttt{numpy.random.default\_rng(seed=42)} shared across cells, except
the analytical-PDF sanity histogram (\S\ref{sec:projection}) which uses
\texttt{seed=123} and the $\Bsel$ bootstrap which uses \texttt{seed=0}.

\section{The intrinsic mass--richness relation (C26 Eq.~15)}
\label{sec:mass-richness}

\modname{Path}\,\pyfile{costanzi\_selection.py}
(\texttt{l\_sat}, \texttt{l\_tr}, \texttt{sample\_lambda\_true}).
Implements the C26 forward model for the intrinsic richness
$\ltr$ as a function of halo mass $M$ and redshift $z$.

\subsection{Mathematical form}

The mean satellite richness follows C26 Eq.~15,
\begin{equation}
\label{eq:lsat}
  \langle \lambda_{\rm sat} | M, z \rangle
  \;=\; \left( \frac{M - M_{\rm min}}{M_{\rm pivot}} \right)^{\!\alpha}
        \left( \frac{1+z}{1+z_{\rm piv}} \right)^{\!\epsilon},
\end{equation}
clipped to zero below $M_{\rm min}$ to avoid a fractional power of a
negative number.  The mean intrinsic richness adds a central
contribution that is unity above threshold and zero below
(C26 Sec.~III):
\begin{equation}
\label{eq:ltr}
  \langle \ltr | M, z \rangle
  \;=\; \begin{cases}
          1 + \langle \lambda_{\rm sat} | M, z \rangle, & M \ge M_{\rm min}, \\
          0, & M < M_{\rm min}.
        \end{cases}
\end{equation}

The DES~Y1 NC+3$\times$2pt best-fit constants hard-coded in
\pyfile{costanzi\_selection.py} are
\begin{equation}
\label{eq:desy1-params}
  \log_{10} M_{\rm min} = 11.385,\quad
  \alpha = 0.859,\quad
  \log_{10} M_1 = 12.696,\quad
  \sigma_{\rm intr} = 0.181,\quad
  \epsilon = 0.284,\quad
  z_{\rm piv} = 0.4544,
\end{equation}
with $M_{\rm pivot} = M_1 - M_{\rm min}$.

The per-halo $\ltr$ is drawn from a compound Poisson with a
multiplicative-lognormal broadening of the Poisson mean (C26
Sec.~III, generative form):
\begin{equation}
\label{eq:lsample}
  m_{\rm broad} \;=\; m_{\rm sat}\,
                       \exp\!\big[\,\sigma_{\rm intr}\,\mathcal N(0, 1)
                                  - \tfrac{1}{2}\sigma_{\rm intr}^2\,\big],
  \qquad
  N_{\rm sat} \,\sim\, \mathrm{Poisson}(m_{\rm broad}),
\end{equation}
with the central galaxy contributing the explicit $+1$ (and only
above $M_{\rm min}$):
\begin{equation}
\label{eq:lsample-final}
  \ltr \;=\; \mathbb 1[M \ge M_{\rm min}] \;+\; N_{\rm sat}.
\end{equation}
The lognormal mean is set so that $E[m_{\rm broad}] = m_{\rm sat}$
exactly, preserving the first moment of the Poisson--Gaussian
convolution stated in C26 to second order in $\sigma_{\rm intr}$.

\subsection{Algorithm}

\begin{algorithm}[H]
\caption{\texttt{sample\_lambda\_true(M, z, rng)}}
\KwConfig{\texttt{M\_MIN}, \texttt{M\_PIVOT}, \texttt{ALPHA},
 \texttt{EPSI}, \texttt{PIVOT\_Z0}, \texttt{SIGM\_INTR}}
\KwData{$M$ (halo mass, $\hMsun$), $z$ (halo redshift)}
\KwResult{$\ltr$ per halo, integer-valued}

$m_{\rm sat} \leftarrow$ \texttt{l\_sat}$(M, z)$ via Eq.~\eqref{eq:lsat}\;
$m_{\rm broad} \leftarrow m_{\rm sat} \cdot$ \texttt{rng.lognormal}$(\mu = -\tfrac{1}{2}\sigma_{\rm intr}^2,\, \sigma = \sigma_{\rm intr})$\;
$m_{\rm broad} \leftarrow$ \texttt{clip}$(m_{\rm broad}, 0, \infty)$\;
$N_{\rm sat} \leftarrow$ \texttt{rng.poisson}$(m_{\rm broad})$\;
\Return $(M \ge M_{\rm min})$ + $N_{\rm sat}$\;
\end{algorithm}

\paragraph{Sanity checks (notebook cells 11--12).}  The notebook
overlays the population-mean curve $\langle\ltr|M, z\rangle$ at three
reference redshifts on a hexbin of the per-halo draws to confirm the
generative mean matches the analytical mean curve, and histograms the
residual $\Delta\log_{10}\ltr = \log_{10}\ltr - \log_{10}\langle\ltr | M, z\rangle$
to expose the asymmetric scatter.  The expected $\langle\ltr\rangle$ on
the post-selection mock is $\sim 5.5$, with the fraction above $\ltr =
20$ at the percent level --- consistent with the low-mass-dominated
halo catalogue.

\section{The projection kernel (C19 Eq.~6)}
\label{sec:projection}

\modname{Path}\,\pyfile{costanzi\_selection.py}
(\texttt{projection\_params}, \texttt{sample\_lambda\_obs}). Maps
$\ltr \to \lob$ via the four-parameter Costanzi+2019 mixture model
calibrated against SDSS redMaPPer.

\subsection{Mathematical form}

C19 Eq.~6 is a Gaussian-core + exponentially-modified-Gaussian (EMG)
mixture:
\begin{equation}
\label{eq:c19-eq6}
  P(\lob | \ltr, z)
  \;=\; (1 - f_{\rm prj})\, \mathcal N(\mu, \sigma)
       \;+\; f_{\rm prj}\, \mathrm{EMG}(\mu, \sigma, \tau),
\end{equation}
with the EMG component
\begin{equation}
  \mathrm{EMG}(\lob ; \mu, \sigma, \tau)
  \;=\; \frac{\tau}{2}\, \exp\!\left[\frac{\tau}{2}\big(2\mu + \tau\sigma^2 - 2\lob\big)\right]\,
        \mathrm{erfc}\!\left(\frac{\mu + \tau\sigma^2 - \lob}{\sqrt{2}\,\sigma}\right).
\end{equation}
The four parameters are linear in their per-redshift coefficients
loaded from \pyfile{prj\_params\_DESY3\_lss\_lin\_dep\_getdist\_v1.txt}
(C19 Appendix~A, Eq.~A8):
\begin{align}
  \mu(\ltr, z)    &= a_\mu(z) + b_\mu(z)\,\ltr,
  & \sigma(\ltr, z) &= b_\sigma(z)\,(\ltr)^{a_\sigma(z)}, \\
  \tau(\ltr, z)   &= b_\tau(z)\,(\ltr)^{-a_\tau(z)},
  & f_{\rm prj}(\ltr, z) &= b_{f_{\rm prj}}(z)\,\big(1 + e^{-\ltr}\big)^{-a_{f_{\rm prj}}(z)}.
\end{align}
The 15 rows of the parameter file are interpreted here as posterior
samples from the upstream getdist chain (NOT redshift knots --- the
$z$-dependence is encoded in the linear coefficients themselves);
\texttt{load\_prj\_posterior\_mean} collapses them to the posterior
mean, which is the operating point used throughout the notebook.

\subsection{Algorithm}

The mixture is drawn directly without evaluating the closed-form EMG
density, exploiting the fact that the EMG is the convolution of an
independent Gaussian and an exponential:
\begin{equation}
  \mathrm{EMG}(\mu, \sigma, \tau) \;\stackrel{d}{=}\;
    \mathcal N(\mu, \sigma) + \mathrm{Exp}(1/\tau).
\end{equation}

\begin{algorithm}[H]
\caption{\texttt{sample\_lambda\_obs(ltr, z, interp, rng)}}
\KwConfig{posterior-mean projection coefficients in \texttt{interp}}
\KwData{$\ltr$ (per halo), $z = \zob$ (per halo)}
\KwResult{$\lob$ (per halo), and the per-halo $(f_{\rm prj}, \tau, \mu, \sigma)$}

$(f_{\rm prj}, \tau, \mu, \sigma) \leftarrow$ \texttt{projection\_params}$(\ltr, z, \texttt{interp})$\;
$g \leftarrow \mu + \sigma \cdot \texttt{rng.standard\_normal}()$\;
$u \leftarrow \texttt{rng.uniform}()$\;
$b \leftarrow \texttt{rng.exponential}(\texttt{scale} = 1/\tau)$\;
\Return $\lob = g + b\,\mathbb 1[u < f_{\rm prj}]$\;
\end{algorithm}

\paragraph{Numerical recipes.}  In the closed-form sanity histogram
the EMG prefactor is computed in log space
($\log[\tau/2] + (\tau/2)(2\mu + \tau\sigma^2 - 2\lob)$) and exponentiated
once, to avoid overflow at large $\tau$, and \texttt{scipy.special.erfc}
is used directly rather than $\texttt{erfcx}$ since the argument here
is bounded and small.  The clamps
$f_{\rm prj} \in [0, 1]$, $\tau, \sigma \ge 10^{-6}$ in
\texttt{projection\_params} guard against pathological coefficient
combinations from outlier posterior draws.

\paragraph{Sanity checks (notebook cells 18--20).}  Two diagnostics:
(a) $\sim 2 \times 10^5$ Monte-Carlo draws at fixed $(\ltr, z)$ are
histogrammed against the closed-form C19 PDF on a log-$y$ scale at
three redshifts $\{0.1, 0.2, 0.3\}$ and three intrinsic richnesses
$\{26, 58, 100\}$; (b) the C19 kernel is decomposed into its
$(1-f_{\rm prj})\,\mathcal N$ Gaussian core and its $f_{\rm prj}\,$EMG
projection tail at $z = 0.4$ for $\ltr \in \{10, 30, 60, 100\}$, to
visualise the EMG tail dominating the high-$\lob$ side at large $\ltr$
and driving the projection bias on the lensing data vector.

\section{Output 1 --- $N(\lob, \zob)$ number counts}
\label{sec:counts}

The number-counts data vector is a direct histogram of the C19
forward-model $\lob$ on the observed-frame $\zob$:
\begin{equation}
  N_{ij}^{\rm fwd}
  \;=\; \sum_{h}
    \mathbb 1\!\left[\, \lob_h \in [\lambda_i, \lambda_{i+1}) \,\right]
    \mathbb 1\!\left[\, \zob_h \in [z_j, z_{j+1}) \,\right],
\end{equation}
on the default $4 \times 3$ grid above.  The two binning quantities
($\lob$ and $\zob$) come from the forward model rather than from the
catalog redMaPPer columns: the abundance side of the data vector lives
in the C26 model world, not in the cluster-finder world.  This is the
correct entry for a C26 likelihood that integrates Eq.~15
$\to$ Eq.~6 to predict $N(\lob, \zob)$.

The headline numbers on the notebook's default grid are
\begin{equation*}
  N(\lob, \zob) \;=\; \begin{pmatrix}
    28\,903 & 71\,482 & 90\,166 \\
     4\,138 &  9\,419 & 11\,699 \\
     1\,242 &  2\,739 &  3\,120 \\
       482 &     941 &     903
  \end{pmatrix},
\end{equation*}
reflecting the steeply falling Buzzard halo mass function and the
photo-$z$ kernel pile-up at intermediate redshift.

\section{Stacked $\Sigma(R)$ in $\lambda$ bins: true vs observed}
\label{sec:stacked-sigma}

The lensing data vector is built by averaging per-halo $\Sigma_h(R)$
inside each $(\lambda, z)$ bin,
\begin{equation}
  \langle \Sigma(R) \,|\, \lambda_i, z_j \rangle
  \;=\; \frac{1}{N_{ij}}\sum_{h \in \rm bin} \Sigma_h(R),
\end{equation}
so the stacked profile is shaped by the \emph{mass distribution
within the bin}.  Because $\Sigma_h$ is fixed by halo mass via the
NFW-like projected profile, comparing two stacks at the same
numerical $\lambda$ but different binning quantities --- one binned
on the intrinsic $\ltr$, one on the observed $\lob$ --- isolates how
optical selection alters that mass distribution.

\paragraph{Mass-dilution piece.}  The $\ltr$ bin samples a narrow
mass range set by the C26 mass--richness relation (the "intrinsic"
richness--mass relation).  The $\lob$ bin additionally pulls in
low-mass halos that got projection-boosted up into the range via
the asymmetric C19 EMG tail.  The expected ordering is
\begin{equation}
  \langle \Sigma | \lob_i \rangle \;<\; \langle \Sigma | \ltr_i \rangle,
\end{equation}
because the $\lob$ bin's mean mass --- and hence its mean $\Sigma$ ---
is dragged down by the extra low-mass halos.  This is the
mass-dilution / Eddington-bias piece of the optical-selection effect
that the forward model captures \emph{without} an explicit $\Bsel$
correction.  The notebook displays the ratio
$\langle\Sigma|\lob\rangle / \langle\Sigma|\ltr\rangle$ in cell~25,
which sits below unity at all $R$ in the lower-richness bins.

\paragraph{C26 Fig.~3 cross-check.}  Cell~27 isolates the
$(\lob \in [15, 25), \zob \in [0.37, 0.51))$ bin (closest to
$(\lob = 20, z = 0.5)$) and replots $\langle\Sigma(R)\rangle$ in
comoving Mpc/$h$ on the $x$-axis and $M_\odot/(\mathrm{Mpc}/h)^2$ on
the $y$-axis to match the C26 Fig.~3 axes.  Visual amplitude and
slope agree with the published reference.

\section{Halo mass function cross-check}
\label{sec:hmf-check}

A sanity check on the abundance side of the data vector: the binned
$dn/d\log_{10} M$ from the Buzzard catalogue inside the volume
\begin{equation}
  V_{\rm sample}
  \;=\; f_{\rm sky}\,\Big[V_{\rm com}(z_{\rm max}) - V_{\rm com}(z_{\rm min})
                      - V_{\rm com}(0.37) + V_{\rm com}(0.33)\Big],
\end{equation}
with $f_{\rm sky} = 4143/41253$ (DES~Y3 Buzzard area), is overlaid
against an analytical Tinker~2008 HMF evaluated at the Buzzard
cosmology with $\sigma_8 = 0.82$, $n_s = 0.96$, the
Eisenstein--Hu transfer function, and the Bryan \& Norman~1998
spherical-overdensity virial mass definition (\texttt{SOVirial} in
\modname{hmf}, matching the Buzzard \blk{Mvir}).  The two agree at
the $10$--$20\%$ level over the relevant mass range, which suffices
for a likelihood that is dominated by the lensing leg --- a future
cosmology run will not be pulled away from the input by an HMF
mismatch.

\section{Output 2 --- $\langle \gamma_t(R)\rangle$ and the empirical $\Bsel$}
\label{sec:lensing-empirical}

The cluster-finder route to the lensing data vector.  The forward
model of \S\ref{sec:projection} produces a $\lob$ that is statistical
in $(M, z)$ alone --- it carries no per-halo line-of-sight (LSS)
information.  Optical-selection bias on the lensing profile only
appears when the binning quantity itself responds to each cluster's
environment.  The Buzzard catalogue already has that quantity:
\blk{LAMBDA\_CHISQ}, the redMaPPer-measured richness produced by
running the cluster finder on the Buzzard photometric mock, and its
self-consistent cluster photo-$z$ \blk{Z\_LAMBDA}.  We use those two
columns as the lensing-side bin definition.

\subsection{Lensing geometry}

The shear-side conversion from $\Delta\Sigma$ to $\gamma_t$ uses the
precomputed $\beta_{\rm eff}$ table loaded from
\pyfile{floc.mock\_boost\_factor\_1d}:
\begin{equation}
  \Sigma_{\rm crit}^{-1}(z_l)
  \;=\; \frac{4\pi G}{c^2}\, D_{\rm com}(z_l)\, \beta_{\rm eff}(z_l),
\end{equation}
with $D_{\rm com}(z_l)$ from \texttt{cosmo0.comoving\_distance} and
the prefactor $4\pi G/c^2 = 6.01 \times 10^{-19}\,\mathrm{pc}/M_\odot
\times 10^{6}$ for the pc-to-Mpc conversion that puts the result in
$\mathrm{pc}^2/M_\odot$.  The data vector is then
\begin{equation}
\label{eq:gamma-t}
  \langle \gamma_t(R) \,|\, \lambda^{\rm RM}, z^{\rm RM} \rangle
  \;=\; \langle \Delta\Sigma(R) \rangle_{\rm bin}\,
        \Sigma_{\rm crit}^{-1}\!\big(\langle z^{\rm RM} \rangle_{\rm bin}\big).
\end{equation}
Because the per-halo \blk{DeltaSigma} column was already
particle-pair-counted on the Buzzard simulation by the upstream
profile pipeline, no $\Sigma \to \Delta\Sigma$ inversion is performed
here.

\subsection{The $(M, z_{\rm true})$-matched random reference}

To isolate the \emph{LSS-correlated} piece of the optical-selection
bias from the mass-dilution piece, we follow Wu+2022 / Esteves
(\pyfile{stacked\_profile\_weighted\_by\_mass\_redshift.py}) and
build a random reference whose $(\log_{10} M, \ztr)$ distribution
matches the cluster-finder-selected sample's, but is drawn
\emph{blind} to the cluster finder.  For each
$(\lambda^{\rm RM}, z^{\rm RM})$ bin and a fixed $(\Delta\log M,
\Delta z) = (0.1, 0.05)$ grid:
\begin{equation}
\label{eq:mass-match}
  \langle \Delta\Sigma(R) \rangle_{\rm rnd}
  \;=\; \frac{\sum_c w_c\, \langle \Delta\Sigma(R) | c \rangle_{\rm full\,mock}}
             {\sum_c w_c},
  \qquad
  w_c = N_c^{\rm sel}.
\end{equation}
The cell-average is taken over the \emph{full} mock, so the
reference resamples halos that share the selected sample's mass and
redshift but were never preferentially picked for their environment.
The empirical selection bias is the per-bin ratio
\begin{equation}
\label{eq:bsel-emp}
  \Bsel^{\rm emp}(R \,|\, \lambda^{\rm RM}, z^{\rm RM})
  \;=\; \frac{\langle \Delta\Sigma(R) \rangle_{\rm sel}}
             {\langle \Delta\Sigma(R) \rangle_{\rm rnd}}.
\end{equation}
$\Bsel^{\rm emp}$ is the catalog-direct analogue of the C26 Eq.~C1
fitting function: no $R \to 0$ extrapolation, no $\Sigma$-vs-$\Delta\Sigma$
calibration assumption, both numerator and denominator come from the
same per-halo \blk{DeltaSigma} column.

\subsection{Algorithm}

\begin{algorithm}[H]
\caption{\texttt{lensing\_data\_vector}(per bin $(\lambda^{\rm RM}_i, z^{\rm RM}_j)$)}
\KwConfig{$\Delta\log M = 0.1$, $\Delta z = 0.05$, \blk{LBDBINS}, \blk{ZMIN\_LIST}, \blk{ZMAX\_LIST}}
\KwData{\blk{LAMBDA\_CHISQ}, \blk{Z\_LAMBDA}, \blk{DeltaSigma}, \blk{Mvir}, \blk{redshift\_true}, $\beta_{\rm eff}$ table}
\KwResult{\blk{shear\_data\_vector} (selected), \blk{shear\_random} (mass-matched), \blk{B\_sel\_emp}}

\For{\rm each $(\lambda^{\rm RM}_i, z^{\rm RM}_j)$ bin}{
  $m \leftarrow$ halos with \blk{LAMBDA\_CHISQ} in $[\lambda_i, \lambda_{i+1})$ and \blk{Z\_LAMBDA} in $[z_j, z_{j+1})$\;
  $\langle\Delta\Sigma\rangle_{\rm sel} \leftarrow$ \texttt{mean}(\blk{DeltaSigma}$[m]$, axis=0)\;
  $\langle\Delta\Sigma\rangle_{\rm rnd} \leftarrow$ \texttt{mass\_match\_stack}$($\
  \quad $\log_{10} M_{\rm vir}[m], \ztr[m], \blk{DeltaSigma}[m],$\
  \quad $\log_{10} M_{\rm vir}, \ztr, \blk{DeltaSigma}, \Delta\log M, \Delta z)$\;
  $\langle z^{\rm RM} \rangle \leftarrow$ \texttt{mean}(\blk{Z\_LAMBDA}$[m]$)\;
  $\Sigma_{\rm crit}^{-1} \leftarrow$ \texttt{interp}$(\langle z^{\rm RM} \rangle, z_{\rm lens}, \beta_{\rm eff}\,\mathrm{table})$\;
  \blk{shear\_data\_vector}$_{ij} \leftarrow \langle\Delta\Sigma\rangle_{\rm sel} \cdot \Sigma_{\rm crit}^{-1}$\;
  \blk{shear\_random}$_{ij}      \leftarrow \langle\Delta\Sigma\rangle_{\rm rnd} \cdot \Sigma_{\rm crit}^{-1}$\;
  \blk{B\_sel\_emp}$_{ij}        \leftarrow \langle\Delta\Sigma\rangle_{\rm sel} / \langle\Delta\Sigma\rangle_{\rm rnd}$\;
}
\end{algorithm}

\subsection{Wu+2022 Fig.~2 reproduction}

The notebook reproduces the Wu+2022 (arXiv:2203.05416) Fig.~2 panel
grid in cells~43--44: per $(\lambda^{\rm RM}, z^{\rm RM})$ bin, the
selected/$(M,z)$-matched ratio is overlaid for both
$\Sigma$ (orange) and $\Delta\Sigma$ (blue) on a log-$x$ axis spanning
$\sim 0.1$--$30$\,Mpc.  The bell-shaped peak around $R \sim 1$\,Mpc
is the LSS-environment-driven selection bias and reproduces the Wu
result.

A 50-sample bootstrap (cell~44) resamples halos within each bin with
replacement and re-builds the mass-matched reference at every step
to capture the statistical uncertainty driven by finite halo count;
in the lowest-$\lambda$ bins this is the dominant source of the
apparent dip and bump structure beneath the bell.

\subsection{Null test on the C19 sampler}

Cell~47 repeats the same panel grid but bins on the C19 forward-model
$(\lob, \zob)$ in place of the catalog $(\lambda^{\rm RM},
z^{\rm RM})$.  The selected/$(M,z)$-matched ratio collapses to
$\approx 1$ at all $R$ as expected, because the C19 sampler is by
construction blind to per-halo LSS environment.  This is a clean
null test of the mass-matching procedure: any residual deviation
from unity is the bias of the matching algorithm itself, not a
physical signal.

\section{The analytical Costanzi+2026 Eq.~C1 closure}
\label{sec:c1}

A purely analytical alternative to \S\ref{sec:lensing-empirical}'s
catalog-empirical ratio.  The C26 Appendix~C fitting function for
the bias on $\Sigma$ is
\begin{equation}
\label{eq:c1-form}
  \Bcal_{\rm sel,C1}^{\Delta\Sigma}(R \,|\, \lob, z)
  \;=\; A\,\left(\frac{R}{R_0}\right)^{\!\alpha}
        \left[\,1 + \left(\frac{R}{R_0}\right)^{\!\gamma}\,\right]^{(\beta - \alpha)/\gamma}
        + C,
\end{equation}
with $R_0 = R_\lambda(\lob)\,(1+z)$ and
$R_\lambda = (\lob/100)^{0.2}\,\hMpc$ (C26 Appendix~B).  The same
functional form fits the bias on $\Delta\Sigma$ (Matteo, private
communication) with a different parameter set.  Both flavours are
implemented in the notebook:
\begin{equation}
  \begin{array}{l@{\quad}l@{\quad}l@{\quad}l@{\quad}l@{\quad}l}
  \multicolumn{1}{l}{\textbf{flavour}} & A & \alpha & \beta & \gamma & C \\[1pt]
  \mathrm{C1\,for}\ \Delta\Sigma\ \text{(Matteo, priv.\ comm.)} & 0.12 & 4.11 & -0.18 & 1.82 & 1.00 \\
  \mathrm{C1\,for}\ \Sigma\ \text{(C26 published)}              & 0.10 & 0.92 & -0.53 & 4.10 & 1.00 \\
  \end{array}
\end{equation}
The C26 paper writes the $\Sigma$ form with a fixed $+1$ rather than
a free $C$, which is the $C = 1$ limit of Eq.~\eqref{eq:c1-form}.

The data vector is then
\begin{equation}
\label{eq:c1-dv}
  \Delta\Sigma_{\rm obs}(R)
  \;=\; \Bcal_{\rm sel,C1}^{\Delta\Sigma}(R \,|\, \lob, z)\,
        \Delta\Sigma_{\rm true}(R),
  \qquad
  \langle \gamma_t(R) \rangle
  \;=\; \Delta\Sigma_{\rm obs}(R)\,
        \Sigma_{\rm crit}^{-1}\!\big(\langle\zob\rangle_{\rm bin}\big).
\end{equation}
The $\Delta\Sigma_{\rm true}$ stack is taken on the C19 forward-model
$(\lob, \zob)$, so the chain
$\ltr \to \lob \to \Delta\Sigma_{\rm obs}$ lives entirely in the
analytical-model world --- distinct from \S\ref{sec:lensing-empirical}
which stacks on catalog redMaPPer outputs.

\paragraph{Why both routes coexist.}  The full C26 forward model
($\Sigma_{1h}$ via Eq.~12 + $\Sigma_{\rm prj}$ via Eq.~13, then
Wright--Brainerd to $\Delta\Sigma$) involves nested
line-of-sight integrals through the optical-bias kernel
$b_{\lob}$ (C26 Eq.~8) that are prohibitive at every likelihood
evaluation.  Eq.~\eqref{eq:c1-form} collapses that calculation into
five constants per richness/redshift bin, which is what makes a
production MCMC tractable.  The empirical $\Bsel^{\rm emp}$ of
\S\ref{sec:lensing-empirical} is the cross-check that the analytical
form actually fits the simulation: the two should agree on a per-bin
basis to within the bootstrap uncertainty of the empirical
construction.

\paragraph{Matteo's binning preset.}  Cell~50 re-runs the analytical
C1 evaluation on the alternative DES~Y3-style grid
$\texttt{LBDBINS\_M} = \{20, 30, 45, 60, 500\}$,
$\texttt{ZMIN\_LIST\_M} = \{0.20, 0.35, 0.50\}$,
$\texttt{ZMAX\_LIST\_M} = \{0.35, 0.50, 0.65\}$, and plots the
$\Bcal_{\rm sel,C1}^{\Delta\Sigma}$ and $\Bcal_{\rm sel,C1}^{\Sigma}$ panel
grid on the comoving-Mpc/$h$ axis with a $y$-range fixed to
$[0.97, 1.13]$ for direct comparison to the C26 reference figure.

\section{Known simplifications}
\label{sec:future}

\begin{itemize}
  \setlength\itemsep{2pt}
  \item \textbf{Photo-$z$ kernel.}  The Gaussian
    $\sigma_z = 0.01\,(1+\ztr)$ proxy is a stand-in for the
    redshift- and colour-dependent kernel of Myles+2021.  It captures
    the dominant scatter but misses the tails that drive the
    high-$z$ outlier rate.
  \item \textbf{Boost-factor contamination.}  Cluster-member
    contamination of the source sample (Y3 boost factors) is not yet
    modelled.  This is the other major Y3 lensing systematic that
    needs to be added on top of the optical-selection bias.
  \item \textbf{Posterior-mean projection.}  The C19 projection
    parameters are evaluated at the posterior mean of the upstream
    chain.  Row-by-row covariance propagation (which would convert
    the parameter posterior into a per-bin $\lob$ distribution) is
    not implemented.
  \item \textbf{Masking and miscentering.}  The masking fraction
    $f_{\rm msk}$ from C19 is loaded but unused; centering
    mis-identification (which is the focus of \S 9 of Esteves'
    \pyfile{pipeline\_modules.tex}) is not modelled here.
  \item \textbf{Single-scale $\Bsel$ in \pyfile{costanzi\_selection.py}.}
    The legacy \texttt{b\_sel\_one\_halo} weight in the helper module
    is the small-scale (one-halo) limit of C26 Appendix~C; it is
    superseded in the production notebook by the scale-dependent
    Eq.~\eqref{eq:c1-form} fitting function, but left in the helper
    for completeness.
\end{itemize}
